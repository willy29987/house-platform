# 房地產 × 短影音 AI 團隊

一套可直接使用的 AI 虛擬團隊，適用於房仲個人品牌、房產代銷、物件銷售與租賃經營。
每個角色都有：**身份設定 / 任務 / 輸出格式 / KPI / 提示詞（可直接貼到 ChatGPT、Claude、Gemini）**。

## 工作流程（建議）

### 每週循環

```
週一 09:00  AI 營運總監 → 輸出本週「目標 + 任務工單」
週一 10:00  各角色領工單 → 按交接格式回覆
週三 AM     中期檢查：內容產出、投放數據
週五 PM     數據分析師 → 週報 → 總監決策「保留 / 淘汰 / 放大」
```

### 單一物件上架流程（從拿到委託到開始導流）

```
房產內容專家  → 產出物件賣點文案
        ↓
短影音腳本    → 3 種題材腳本（痛點式 / 比較式 / 生活式）
        ↓
短影音導演    → 拍攝分鏡 + B-roll 清單 + 字幕風格
        ↓
發文小幫手    → 改寫成 IG / FB / Threads / 小紅書 版本
        ↓
法律顧問      → 審廣告用語（實坪、保證、學區等）
        ↓
流量投手      → 開廣告測試 3 組受眾
        ↓
私訊成交助手  → 準備 FAQ 與第一層篩選話術
        ↓
數據分析師    → 設定 UTM、追蹤轉換
```

## 使用方式

### 方式 0（推薦）：在後台面板直接對話

本專案已內建「AI 團隊面板」，登入後台後開啟：

```
/admin/team
```

- 左邊點成員、右邊直接對話（文字或麥克風語音）
- 每位成員會自動載入對應 `.md` 裡的「提示詞」當 system prompt
- 對話紀錄儲存在你的瀏覽器（localStorage），不會外傳
- 每個成員都有「快速指令」按鈕，點一下就能開工

#### 啟用條件（環境變數）

在 `.env` 或 Vercel 設定：

```
AI_API_KEY=你的金鑰
AI_BASE_URL=https://api.openai.com/v1   # 可選，換其他 OpenAI 相容服務
AI_MODEL=gpt-4o-mini                    # 可選，預設 gpt-4o-mini
```

支援 OpenAI 相容介面的任何服務（OpenAI / DeepSeek / Moonshot / Gemini OpenAI 相容模式 / 自架 vLLM…）。

---

### 方式 A：在 ChatGPT / Claude 中建立多個對話

1. 每個角色開一個獨立對話
2. 將該角色 `.md` 裡的「提示詞」整段貼到第一則訊息
3. 之後就把該角色當成真實員工溝通

### 方式 B：用 Claude Projects / ChatGPT GPTs / Gemini Gems

1. 每個角色建立一個 Project / GPT
2. System Prompt 就放該角色的「提示詞」區塊
3. 把「共用模板」(`_templates/`) 當 Knowledge 附上

### 方式 C：一人分飾多角

直接跟總監對話即可，總監會依情境自行呼叫下屬角色。
適合剛開始、節省時間的做法。

## 溝通協定（所有角色共用）

1. **工單優先**：每個任務用 `_templates/工單.md` 格式派發
2. **交接優先**：輸出時使用 `_templates/交接.md` 格式，方便下一棒接手
3. **一次一事**：避免一個工單塞 3 件以上任務
4. **數據說話**：產出後一定附上「衡量指標」與「判斷保留 / 淘汰的門檻」

## 第一次使用建議

先只做三件事，不要一次全開：

1. 開 `00-AI營運總監.md`，把提示詞貼進去，告訴它：
   「我的主力是[區域]的[房型]，目標客群是[族群]，這個月想要[目標]。請排出本週任務。」
2. 照總監給你的工單，只啟動 **腳本企劃 + 發文小幫手 + 法律顧問** 三個角色。
3. 一週後再把 **流量投手 + 數據分析師** 加進來。
